Hak akses API, rollback audit, log atribut sensitif, payload siswa berlebihan, query seluruh data, lingkungan test tidak terisolasi, seed identitas menyerupai data pribadi, endpoint HTTP hardcode. Daftar dengan sumber ada di laporan baseline.

## Akses (status setelah Fase 01a)
Penegakan backend terpusat via Gate bernama (tanpa bypass admin). Endpoint master/siswa/pegawai/roles/abilities dilindungi `can:`. FirstLogin terikat actor; atribut administratif akun dilindungi; `check-auth` diminimalkan; register publik ditutup. Default deny untuk kemampuan tak terdaftar. Kemampuan modul yang belum ada (izin/pembelajaran) baru sebatas katalog/kemampuan, belum ada enforcement pada fitur yang belum dibangun. **(Koreksi 2026-11-01: surat masuk kini memiliki enforcement nyata — sembilan route `/api/letters/incoming` memakai `letters.view`/`letters.manage`; `letters.approve`/`letters.sign` tetap belum dipakai sampai 07b.)**
